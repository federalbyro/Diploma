# Конфигурация

Все настройки задаются через `.env`. Файл `.env.example` содержит
значения по умолчанию для локального запуска.

```bash
cp .env.example .env
```

## Переменные

### PostgreSQL

| Переменная      | По умолчанию | Описание              |
|-----------------|--------------|-----------------------|
| POSTGRES_DB     | diploma      | Имя базы данных       |
| POSTGRES_USER   | postgres     | Пользователь          |
| POSTGRES_PASSWORD | postgres   | Пароль                |
| POSTGRES_DSN    | *(строка)*   | DSN для SQLAlchemy    |

### Модель

| Переменная        | По умолчанию                    | Описание                               |
|-------------------|---------------------------------|----------------------------------------|
| MODEL_NAME        | sentence-transformers/LaBSE     | HuggingFace model id                  |
| MODEL_LOCAL_PATH  | *(пусто)*                       | Путь к дообученной модели (если есть) |
| MODEL_DEVICE      | cpu                             | `cpu` или `cuda`                      |
| MODEL_CACHE_DIR   | /models                         | Папка кэша модели (Docker volume)     |
| MODEL_BATCH_SIZE  | 16                              | Размер батча при инференсе            |

### Поиск

| Переменная            | По умолчанию | Описание                                     |
|-----------------------|--------------|----------------------------------------------|
| PRODUCT_SEARCH_LIMIT  | 50           | Топ-N товаров из Qdrant за один запрос       |
| SUPPLIER_TOP_K        | 10           | Количество поставщиков в ответе              |
| CATEGORY_TOP_K        | 5            | Топ-K категорий для каждого товара           |
| SUPPLIER_MIN_SIMILARITY | 0.20       | Минимальный порог сходства                   |
