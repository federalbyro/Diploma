## Назначение

Тесты проверяют полный цикл работы системы:

```text
1. подготовка тестовой базы данных;
2. применение миграций;
3. очистка тестовых коллекций Qdrant;
4. загрузка категорий;
5. обработка каталогов поставщиков;
6. построение эмбеддингов;
7. семантическое сопоставление товаров с категориями;
8. поиск поставщиков по пользовательскому запросу;
9. проверка клиентского API.
```

---

## Запуск тестов

Из корня проекта:

```bash
docker compose exec catalog_service sh -lc "python -u test/run_pytest.py"
```

---

## Что делает run_pytest.py

```text
1. Настраивает переменные окружения для тестов.
2. Создаёт базу данных diploma_test, если её нет.
3. Полностью очищает схему public.
4. Удаляет тестовые коллекции Qdrant.
5. Применяет Alembic-миграции.
6. Запускает интеграционные тесты pytest.
7. Печатает итоговые таблицы по PostgreSQL, Qdrant и метрикам.
```

---

## Основные тестовые сценарии

```text
test_catalog_pipeline.py
```

Проверяет загрузку каталогов, сохранение товаров, построение эмбеддингов и сопоставление с категориями.

```text
test_search_pipeline.py
```

Проверяет внутреннюю логику поиска поставщиков по текстовым запросам.

```text
test_client_service_api.py
```

Проверяет HTTP API клиентского сервиса просто!.
